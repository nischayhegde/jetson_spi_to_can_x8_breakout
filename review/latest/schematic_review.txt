4. STARTUP BIAS: native CS pull-ups are present; define both bank inputs too.

R34-R37 are 100 kohm pulls to VDD_VIO / 3.3 V on the four native CS lines.
They are on the header side of R4/R5/R19/R20. This is electrically acceptable:
moving across 33 ohm makes a negligible difference compared with 100 kohm.
No rewiring is required solely to move these pull-ups after the series parts.
R7/R8/R11/R14/R17/R24/R27/R30 pull individual CAN nCS pins up to 3.3 V.

No board-side bias is present on GPIO_7 (J1.32) or GPIO_11 (J1.31).
Define their startup states with confirmed carrier/boot pinmux behavior, or
consider weak board-side pull-downs such as 100 kohm where appropriate.
Both native CS HIGH deselect every CAN channel regardless of bank state;
nevertheless floating CMOS gate inputs should not be left undefined.

The Orin developer carrier uses TXB0108 translators on these signals. TI
requires external pulls greater than 50 kohm when used. A 100 kohm pull is a
starting bias value, not a guarantee that it overrides an enabled translator
or an opposing SoC pull. Confirm native CS HIGH and defined bank levels during
power-up/reset, before the Linux SPI driver runs. Change bank only while both
native CS are HIGH and the previous CAN SDO has released the MISO bus.

5. LOGIC VERIFIED: bank selection and the combined interrupt are correct.

All 16 bank/native-CS combinations were evaluated from actual gate nets:

  bank=0, native CS0 active -> CAN2 on SPI0 / CAN6 on SPI1
  bank=0, native CS1 active -> CAN3 on SPI0 / CAN7 on SPI1
  bank=1, native CS0 active -> CAN1 on SPI0 / CAN5 on SPI1
  bank=1, native CS1 active -> CAN4 on SPI0 / CAN8 on SPI1

Both native CS HIGH deselect all four channels. Never assert both native CS
LOW on one physical bus: that selects two devices and can contend on MISO.
Use the actual mapping above when defining software mux children.

U4 NAND output pin8 feeds U2F input pin13; U2F output pin12 drives GPIO_1 /
J1.29. This produces AND(nINT1..nINT8), so the Jetson interrupt is now
active LOW and goes LOW whenever any CAN controller asserts its interrupt.
All 256 interrupt input combinations passed. The eight push-pull outputs are
separate NAND inputs, not directly tied together. Default push-pull operation
does not require an external pull-up at every nINT pin. If software selects
open-drain outputs, each separate gate input needs a suitable pull-up.

U2E unused input pin11 is tied to 3.3 V and output pin10 is NC: correct with
U2 now supplied at 3.3 V. The two old free-standing NC markers can be removed.

For software, configure the shared interrupt LEVEL_LOW. All eight CAN devices
need the same IRQ and compatible shared handling. Current upstream mcp251xfd
requests IRQF_SHARED | IRQF_ONESHOT; the exact installed JetPack kernel and
GPIO mux/device-tree topology still require testing. Hardware gating does not
by itself make four devices per SPI bus enumerable by the stock configuration.

At 3.0-3.6 V and the reviewed load/temperature conditions, the selected OR's
maximum delay is 5 ns and the NOT's is 6 ns. Native CS passes through one OR;
bank changes traverse at most NOT+OR, about 11 ns before PCB effects. These
parts suit MHz operation at their now-correct 3.3 V supplies. Actual Jetson CS-to-
clock setup, hold and MISO release timing still needs verification; preserve
the earlier initial 100 ns CS setup / 300 ns device-change gap targets as
prototype margins rather than treating propagation delay alone as proof.

6. VERIFIED ON ALL EIGHT CAN CHANNELS.

Every per-channel check passes in channel_audit.csv / audit_results.json:
CAN1-CAN4 use SPI0 SCK/MOSI/MISO; CAN5-CAN8 use SPI1. Each SDO reaches only
its own bus through its individual 33 ohm resistor. Each nCS is distinct and
matches its channel label. CAN5/CAN6 no longer share CAN7's select.
Each nINT reaches the correct NAND input. Each TXCAN15 connects to TXD23,
and RXD28 connects to RXCAN16. STBY5, VSS22 and GND24 are grounded. Both crystal
case pads are grounded; crystal active pads and two 27 pF capacitors connect
correctly. Each CAN has the intended three 100 nF rail bypass capacitors.
CANH4/CANL3 go to connector pins1/2, with common GND on pin3 and 120 ohm across
the differential pair. Unused secondary interrupt/GPIO/clock pins are NC.

C18/C19 provide nominal 1 uF at the TLV755 input/output. Keep them physically
close and ensure effective capacitance remains above TI's 0.47 uF minimum
after tolerance, bias and temperature. EN tied to the input is valid. Check
SOT-23-5 LDO heating; at 200 mA the nominal dissipation is about 0.34 W.

The 27 pF C0G values remain a reasonable prototype choice, not a proven exact
oscillator load: 27 pF / 2 plus 4.5 pF effective stray gives 18 pF. Microchip
also reports a tested 18 pF external-capacitor population for this crystal.
Measure oscillator startup/frequency and tune for the actual PCB.

7. RECOMMENDED BEFORE LAYOUT / PROTOTYPE.

Only J1.39 is grounded. Connect the available J1 ground pins 6/9/14/20/25/30/34
as well to improve return paths near SPI signals. Keep the local 3.3 V LDO
output independent of the Jetson 3.3 V supply. The SPI header pin assignments
match the intended Orin developer-carrier pinout. GPIO labels must be matched
to the exact carrier and device-tree names rather than assumed universal.

The eight 120 ohm terminations are permanently connected. That is correct if
each port is an endpoint and the other end has one termination. Use exactly
two terminations per CAN bus. Add jumpers or DNP options if these ports may
instead be used in the middle of a bus or with already-terminated equipment.

There are no external CAN TVS parts in this revision; they were removed from
the active CAD library as requested. They are optional for basic signaling,
but connector-side protection is still worth considering for the robot's
motor wiring. Integrated ESD ratings do not prove the complete harness/system
immune to the robot's actual disturbances.

Keep each 33 ohm source resistor near its driver, especially each CAN SDO
resistor. Verify SPI edges and aggregate input/interconnect capacitance at
the carrier translators. CAN bitrate is separate from SPI edge rate.

Most CAN symbols lie outside the A4 drawing border (negative Y or Y>210 mm).
The normal page export clips them. Move blocks inside a larger page or use
separate sheets before sharing plots. The review images can_spi0.png and
can_spi1.png use expanded SVG bounds so all channels were inspected anyway.
